# 🤖 AI 编程工具使用方式

目前会使用 Codex 等 AI 编程工具辅助真实开发。

AI 对我现阶段最大的价值是：

- 帮助快速理解陌生项目
- 根据已有代码寻找调用链
- 辅助定位文件
- 解释报错
- 辅助修改代码
- 帮助完成暂时超出当前能力的真实需求

但学习目标不是：

> AI 写完 → 复制 → 功能能跑就结束。

而是逐渐变成：

```text
AI 帮助实现
   ↓
我知道它改了哪里
   ↓
我看懂整体结构
   ↓
我理解具体语法
   ↓
我能自己修改
   ↓
我能模仿着写
   ↓
最终独立完成
```

同时已经认识到：

> **AI 生成的代码能运行，不代表代码质量一定好。**

后续需要通过公司已有优秀代码、师傅的 Code Review、重构和代码规范逐渐培养自己的代码质量判断能力。
