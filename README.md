# industrial-development-learning

> 我的工业软件全栈开发与工业AI学习记录

## 项目简介

本项目用于记录我在工业软件开发、MES系统维护、全栈开发、数据处理和工业AI方向上的学习过程，包括学习笔记、示例代码、实践项目、问题总结和阶段成果。

我目前主要从事MES系统的基础开发与维护工作，以Java作为主要开发语言。在现有工作基础上，我将逐步学习Spring Boot、PostgreSQL、Redis、Linux、JavaScript、TypeScript、Vue、UniApp以及Python和人工智能相关技术。

本项目的目标不是放弃现有的Java和MES开发方向，而是逐步建立完整的工业软件全栈开发能力，并在此基础上继续学习机器学习、大语言模型、RAG、AI Agent和MCP，探索人工智能在工业软件中的实际应用。

## 学习方法

每个知识点尽量按照以下过程学习：

1. 理解基本概念
2. 跟随课程完成练习
3. 独立重新编写代码
4. 完成一个小案例
5. 总结常见问题
6. 提交代码和学习笔记
7. 接受阶段成果检验
8. 尝试应用到MES或工业场景

## 技术学习原则

* Java作为主要后端开发语言
* Spring Boot作为主要后端框架
* JavaScript是前端基础，学完后再学习TypeScript
* Vue 2用于维护现有项目
* Vue 3与TypeScript用于新项目开发
* UniApp在掌握Vue后学习
* PostgreSQL用于保存正式业务数据
* Redis用于缓存和临时状态
* Linux与CentOS用于服务器部署和运维
* Python主要用于数据分析和AI开发
* AI学习建立在编程、数据库和业务基础之上
* 所有知识尽量通过工业业务案例进行验证
